# IPA files

**Do not use git copies for NekoJB.** The patched build is only on the release (GitHub blocks 100MB+ files in the tree).

- NekoJB Fixed **2.1.0** (~138 MB):
  https://github.com/256r9djs5n-lgtm/Vlib/releases/download/files/NekoJB-Fixed.ipa

If the file is ~84–87 MB or the app version is 2.0.11, it is the **old** unpatched IPA.

How to tell you have 2.1.0:
- TrollStore version: **2.1.0**
- File size: **~138 MB** (144386219 bytes)
- Home screen: no “Forked and modified by HAHALOSAH” / Dopamine credit line
- Package manager picker: Sileo, Zebra, Cydia, Saily, Installer
